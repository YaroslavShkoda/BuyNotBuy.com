# Фикстуры

Три файла, и только один из них называется тем, чем является.

## `btcusdt-1h.csv` — BTCUSDT, Binance, часовые, 50 286 баров

Тот самый инструмент, которым система торгует, в том разрешении, в котором она
работает. С 2021-01-01.

## `btcusdt-1d-binance.csv` — BTCUSDT, Binance, дневные, 2096 баров

Тот же инструмент в дневном разрешении, полученный независимой загрузкой, а не
ресемплингом часовых. Существует затем, чтобы ресемплинг было чем проверить:
`src/backend/research/resample.ts` строит из часовых дневные бары, и они
сравниваются с этим файлом бар в бар.

Проверено: 2088 сопоставленных дней, 0 расхождений по открытию, максимуму,
минимуму и закрытию. Восемь дней пропущены — у них в часовом фиде меньше
24 баров, и дневный бар из неполного набора имеет максимум и минимум, которых
рынок не достигал. Такие дни не строятся.

## `btcusdt-1d.csv` — **Yahoo Finance BTC-USD**, дневные, 2934 бара

Файл называется `btcusdt-1d.csv`, но это не BTCUSDT и не Binance. Это спотовый
индекс Yahoo, граница суток — 12:00 UTC, значения вроде 29376.45583441.

В нём измерено всё, что этот проект утверждал о своих стратегиях до шага
«сбор часовых баров». Он остаётся на месте намеренно: это доказательная база
для тех измерений, и удалять её — значит уничтожить возможность их перепроверить.

Насколько он далеко от того, чем система торгует, измерено по одинаковым
24-часовым окнам на 2064 днях:

| | |
|---|---|
| среднее расхождение закрытия | 1.24% |
| среднее расхождение максимума | 0.80% |
| наибольшее расхождение максимума | 12.54% (2021-07-25) |

Это не округление. День, в который Yahoo показывает максимум 33155.12, биржа
показывает максимум 34778.11 — и правило, поставленное по одному, ставит стоп
в одном месте и не в другом.

## `ethusdt-1d.csv` — ETHUSDT, Binance, дневные, 2096 баров

Второй инструмент. Тот же обмен, то же разрешение, те же даты, что и у BTCUSDT,
чтобы сравнение не подменяло разницу между инструментами разницей между
источниками.

## Как это воспроизвести

```
node --env-file=.env --import=tsx src/backend/research/fetch-fixtures.cli.ts
```

Скрипт загружает данные, сверяет ресемплинг с независимой загрузкой и **не
записывает ничего**, если сверка не сошлась. Он также печатает расхождение со
старой фикстурой — потому что расхождение, о котором не сообщают, хуже, чем
расхождение, о котором сообщают.
